# Work

What is being built right now. One file per task. When you open this folder, you see exactly what is in flight.

- A task file is for bigger work: work that spans more than one session, or that the owner asked for as a feature. A quick fix does not get one.
- Start from the [task template](../rules/docs/task-template.md).
- When a task is done, its result is written into `docs/`, its line leaves [NOW.md](../NOW.md), and its file moves to `archive/`.

The rules are in [using the documentation](../rules/docs/using-the-documentation.md).
