# Work

Where the work is tracked, and in what order.

Every piece of work on {{PROJECT}} is a [GitHub issue on the code repository]({{ISSUES}}): every bug, every feature, every idea, every decision waiting on the owner. The shape an issue takes, and how one is worked and closed, is the [issues rule](../rules/code/issues.md). Nothing is tracked in a file here.

What this folder holds:

- [order.md](order.md): the owner's order for the work, as tiers. Each tier is a milestone on GitHub.
- [plans/](plans/README.md): the plans that issues were drawn from, kept while they are still read. A plan is not a tracker; the issue is.

The rules are in [using the documentation](../rules/docs/using-the-documentation.md).
