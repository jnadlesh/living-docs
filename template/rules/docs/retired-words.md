# Retired words

Words we stopped using, and what to write instead. One word per thing: a second word for the same thing reads as a second thing.

The check fails when a retired word appears in the pages, the rules, the README or NOW.md. It does not look inside `archive/`, `decisions/`, `reference/` or `work/`, because those record what was said at the time. Words inside backticks and link addresses are not checked either, since a file may still carry an old name.

Add a row when something is renamed. Never remove a row.
