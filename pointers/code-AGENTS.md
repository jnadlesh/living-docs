# Where the documentation is

All documentation for {{PROJECT}} lives in a separate repository at `{{DOCS_FROM_CODE}}`, relative to this folder. It is the single source of truth. If that path does not exist from where you are, for example inside a worktree, look for a folder named `{{DOCS_NAME}}` beside the main checkout of this repository.

Before you do anything:

1. Read `README.md` and `NOW.md` there.
2. Read `rules/using-the-documentation.md` and `rules/working-with-the-owner.md` there.

The rules that never change:

- Look it up before you build it. If the documentation has a page for it, it exists. Use it.
- No work is done until the documentation is updated.
- Project facts go in the documentation, not in your private memory.
